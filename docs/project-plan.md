#***studyFlow*** - Project Plan

##1. Project Overview

StudyFlow is a web App made for ***Students*** who want to keep their studies and daily academic work *organized* in one place.

This idea is simple: instead of using different apps for tasks, and tracking progress, studyFlow brings these things together in one dashboard.

I'm building this project as my first **full-stack** portfolio project, so I'll be Developing it step by step while learning how frontend, backend, database, and other parts off real web application work together.
